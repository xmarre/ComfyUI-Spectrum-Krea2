# Spectrum Krea 2 v0.1.0 — GPU-validation prerelease

Initial native ComfyUI Krea 2 integration of **Spectrum** feature forecasting for RAW and Turbo models. This is a prerelease intended for paired image-quality and performance validation.

## Features

- **Spectrum Apply Krea 2** as a MODEL → MODEL node after the final model/LoRA loader.
- Capture the native generated-image transformer features before the output layer, fit causal Chebyshev ridge history and project forecasts through the native current-timestep output head. No additional transformer or model weights.
- RAW and Turbo profiles; Euler and DPM++ 2M source-contract gating, bounded forecasting, optional one-point second-step bootstrap, per-invocation session ownership, stream isolation and native fallback.
- CPU-tested reference conditioning, CFG and batch packing, odd spatial shapes, image-to-image denoise, native LoRA weights, singleton-frame 5D latents and callback/exception cleanup.
- Matched UI and API example workflows, GPU benchmark runner and paired-image comparison utilities.

## Verification

- GitHub Actions: 136 CPU tests passed in the latest Python 3.12/current-container lane. Python 3.10/3.13 and an earlier sampler-container lane also passed.
- 16 full native ComfyUI CPU integration cases passed for each of the audited sampler containers using **small random test weights**.
- CPU tests establish routing, native-output parity for disabled/all-actual execution, lifecycle safety and forecast execution, not production image fidelity.

## Limitations and validation requirement

**Real-checkpoint image quality, CUDA precision and speed, peak VRAM and actual acceleration remain unverified.** No published default is claimed to be a measured quality/speed optimum. Forecast counts alone are not speedup data.

Start with the conservative paired RAW (52 steps, CFG 4.5) or Turbo (8 steps, CFG 1) Euler/simple examples at 1024×1024. Compare the same seed, model, text encoder, VAE and LoRAs with and without Spectrum. Inspect composition, text, anatomy and small detail and measure wall time and memory. See [GPU validation](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/blob/main/docs/GPU_VALIDATION.md).

Use ComfyUI Patcher to install the release and restart ComfyUI. Unsupported samplers, modified transformer contracts and unsupported conditioning paths fall back to native execution.
