# Spectrum Krea 2 v0.2.1 — corrected new-node defaults

This release aligns the node's initial controls with the tested Krea 2 Turbo non-bootstrap configuration. No sampling solver, forecast mathematics, numerical gate, or model interception logic has changed since v0.2.0.

## Defaults for newly inserted nodes

- `preset=turbo`, `degree=1`, `ridge=0.01`
- `warmup=2`, `tail=1`, `window=1`, `growth=0`
- `bootstrap=false` to avoid the unvalidated one-point second-step feature hold
- `extrapolation_guard_enabled=true`, `max_extrapolation_span_ratio=0.50`
- `sa_pece_forecast_policy=off`; `balanced_detail` and other PECE skip modes remain opt-in until their own real-checkpoint quality tests
- `storage=vram`, `max_history=8`, `budget_mb=4096`, `debug=false`

**RAW users must select the RAW profile for RAW weights.** The RAW example intentionally retains its independent 4/2 warmup/tail settings for more conservative initial comparisons. Existing saved workflows and imported examples keep their stored widget values; changing Python/UI defaults does not rewrite saved workflows.

## Validation evidence and limits

A 2026-11-17 externally supplied paired Krea 2 Turbo ER-SDE sample at 3920 × 5888 pixels showed close visual composition. At 980 × 1472 downsampled resolution, the two JPEGs measured SSIM 0.9272 and PSNR 22.55 dB. Spectrum's planner used 9 real + 5 forecast evaluations in 14 steps; its four-step high-resolution pass performed zero forecasts due to the 0.50 extrapolation-distance guard. Total prompt durations (114.88 s Spectrum, 112.35 s native) were not directly comparable because model/text encoder/LoRA cache warmth differed. These data do not constitute a measured speedup or establish fidelity across prompts and seeds; the source JPEGs are not part of this release.

The default-only change is covered by schema/constructor/applied-wrapper agreement and saved-workflow explicit-override tests; bootstrap-specific tests explicitly opt in. CPU CI remains the structural release gate. See the [validation record](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/blob/main/docs/VALIDATION.md) and [GPU protocol](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/blob/main/docs/GPU_VALIDATION.md). Real-checkpoint SA-PECE quality, CUDA precision, peak VRAM and representative end-to-end performance still require controlled evaluation.

Install or update through ComfyUI Patcher. This release contains the merged PR #2 interoperability code and retains the optional companion overlay requirements documented in the [README](https://github.com/xmarre/ComfyUI-Spectrum-Krea2#readme).
