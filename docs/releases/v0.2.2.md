# Spectrum Krea 2 v0.2.2

The extrapolation distance guard can now be applied separately to the Scale-Locked planner and the high-resolution refinement passes.

## Configuration

Keep `extrapolation_guard_enabled=true` and set `extrapolation_guard_scope` to one of the following values.

| Scope | Where the distance guard applies |
|---|---|
| `all` (default) | Planner and every high-resolution pass |
| `planner_only` | Planner, or the first segment of spectral-progressive sampling |
| `highres_only` | Every high-resolution pass, including later spectral-progressive segments |

Stage selection requires [Scale-Locked Residual Diffusion v1.3.2](https://github.com/xmarre/ComfyUI-ScaleLockedResidualDiffusion/releases/tag/v1.3.2) or later. Standalone samplers follow the master guard switch. Turning that switch off disables the distance limit everywhere. The other forecast checks still apply, and the session summary reports the stage and effective guard state.

Saved workflows retain their widget values. The new selector defaults to `all`, which preserves the previous guard behavior. Use ComfyUI Patcher to update to the released versions and remove the merged [Spectrum #5](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/pull/5) and [Scale-Locked #21](https://github.com/xmarre/ComfyUI-ScaleLockedResidualDiffusion/pull/21) / [#22](https://github.com/xmarre/ComfyUI-ScaleLockedResidualDiffusion/pull/22) overlays.

## Validation

Native ComfyUI CPU tests verify guard routing and exact forecast counts on fixed schedules. One real-checkpoint ER-SDE run with `planner_only` used five guarded planner forecasts and one forecast on each of two unguarded refinement passes. This verifies the routing in that run. Broader image fidelity and reproducible GPU speedup remain unmeasured.
